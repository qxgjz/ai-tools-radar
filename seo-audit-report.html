🔧 技术SEO修复清单

配置Google Search Console和GA4 P0

这是最紧急的技术SEO任务，没有数据就无法优化。

步骤：1. 注册GA4获取Measurement ID 2. 替换index.html中的G-XXXXXXXXXX 3. 注册Search Console 4. 验证网站（HTML标签或DNS）5. 提交sitemap.xml 6. 等待数据收集

添加Article、FAQ、Breadcrumb Schema P1

结构化数据能提升搜索结果展示（富摘要），提升点击率。

在文章页动态注入JSON-LD：Article（标题、作者、日期、图片）+ FAQPage（每个Q&A）+ BreadcrumbList（首页 > 分类 > 文章）

添加hreflang标签 P2

多语言网站需要hreflang标签告诉Google不同语言版本的关系。

在head添加：<link rel="alternate" hreflang="zh-CN" href="...?lang=zh"> <link rel="alternate" hreflang="en" href="...?lang=en"> <link rel="alternate" hreflang="x-default" href="...">

🔧 页面SEO修复清单

工具详情页动态标题和Meta描述 P0

目前所有工具详情页共用首页标题，这是严重的SEO问题。每个工具详情页应该有独立的标题和Meta描述。

在renderToolDetail函数中添加：document.title = tool.name + ' - 评测、价格、替代品 | AI Tools Radar'; document.querySelector('meta[name=description]').setAttribute('content', tool.name + '是一款' + tool.category + '工具。' + tool.description.substring(0,120));

文章页动态OG和Twitter标签 P1

文章页缺少独立的OG和Twitter Card标签，影响社交媒体分享效果。

在文章渲染函数中动态更新og:title、og:description、og:image、twitter:title、twitter:description

增加内部链接和外部链接 P1

每篇文章至少5个内部链接（指向相关工具和文章），至少2个外部权威链接（指向工具官网、权威媒体）。

在文章模板中添加"相关工具推荐"和"延伸阅读"模块，每篇文章自然融入5+内链
