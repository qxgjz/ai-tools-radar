## 自动化工作流（7个）

| 工作流 | 频率 | 功能 | 文件 |
|--------|------|------|------|
| maintain.yml | 每周 | 更新 sitemap、lastUpdate | 已有 |
| lighthouse.yml | 每次推送 | 性能检测 | 已有 |
| link-checker.yml | 每周一 | 死链检测 | 已有 |
| accessibility.yml | 每周一 | 可访问性检测 | 已有 |
| weekly-content.yml | 每周一 | 内容生产计划+任务 | 新增 |
| seo-monitor.yml | 每周一 | SEO关键词排名监控 | 新增 |
| monthly-report.yml | 每月1号 | 月度数据分析报告 | 新增 |

### 工作流触发方式
1. **自动触发**：按 cron 表达式自动运行
2. **手动触发**：在 GitHub Actions 页面点击 "Run workflow"
3. **推送触发**：代码推送时自动运行（lighthouse）

- [ ] 发布 1 条社交媒体帖子

- [ ] 死链检测 + 修复
- [ ] 可访问性检测 + 修复

## 如何使用

### 1. 查看运营手册
```
打开 ops/playbook.md
```

### 2. 查看本周内容计划
```
打开 ops/reports/weekly-content-plan-*.md
或查看 GitHub Issues（标签：weekly）
```

### 3. 查看 SEO 报告
```
打开 ops/reports/seo-report-*.md
```

### 4. 查看月度报告
```
打开 ops/reports/monthly-report-*.md
```

### 5. 手动触发工作流
```
GitHub → Actions → 选择工作流 → Run workflow
```

### 6. 使用内容模板
```
打开 ops/content/ 目录，选择对应模板
```
