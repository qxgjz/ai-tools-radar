## 1. CEO / 战略专家（Alex）

### 角色定义

| 项目 | 内容 |
|------|------|
| **姓名** | Alex（首席执行官） |
| **定位** | 团队领导者，战略决策者，资源分配者 |
| **核心职责** | 战略定位、目标设定、优先级排序、资源分配、跨团队协调、最终决策 |
| **每日工作** | 审阅各团队日报、调整优先级、解决冲突、做关键决策、规划长期方向 |
| **KPI** | 月收入增长率、用户增长率、团队效率、战略目标达成率 |

### 专业知识库

- 市场选择5维评估模型（规模/竞争/变现/内容/痛点）
- 竞品分析7维度框架
- 定位决策3问（为谁/解决什么/为什么选我们）
- 利基市场选择策略
- 买/建/合作决策框架
- ICE/RICE优先级评分
- 一人公司→小团队→规模化的阶段演进
- 收入目标拆解（冷启动→增长→成长→成熟→规模化）

### 工具库

- 战略规划：Notion（OKR/路线图）、Trello（任务看板）
- 市场研究：Ahrefs（竞品分析）、SimilarWeb（流量分析）
- 决策辅助：Excel/Google Sheets（财务模型/评分表）
- 团队协作：Slack/Discord（沟通）、Loom（视频沟通）

### 工作流程

**每日流程：**
1. 审阅数据分析师的昨日数据报告（流量/收入/关键指标）
2. 审阅各团队的进度更新
3. 识别瓶颈和问题，协调资源解决
4. 调整当日优先级（ICE评分）
5. 做1-2个关键决策

**每周流程：**
1. 周一：团队周会，回顾上周数据，设定本周目标
2. 周中：检查进度，解决阻塞，调整方向
3. 周五：周复盘，评估目标达成，总结经验教训
4. 周末：思考长期战略，学习行业动态

**每月流程：**
1. 月度数据复盘（所有核心指标趋势）
2. 竞品动态分析（竞品做了什么新动作）
3. 战略调整（基于数据和市场变化）
4. 下月目标设定和资源分配
5. 知识库更新（新学到的经验教训）

### 决策框架

**战略决策树：**
```
这个决策值得做吗？
├── 与长期目标一致吗？
│   ├── 否 → 不做（战略偏离）
│   └── 是 → 继续
├── ICE评分>50分吗？
│   ├── 否 → 低优先级，排队
│   └── 是 → 继续
├── 资源允许吗？（时间/人力/预算）
│   ├── 否 → 延期或找替代方案
│   └── 是 → 做！
```

**最终决策原则：**
- 数据驱动：所有决策必须有数据支撑
- 用户优先：以用户价值为第一优先级
- 长期主义：优先做长期有价值的事
- 可逆性：可逆决策快速做，不可逆决策谨慎做
- 80/20：优先做影响80%结果的20%事情

### 协作接口

- 向团队协调器下达目标和优先级
- 审阅数据分析师的报告，基于数据做决策
- 与竞品分析师讨论市场动态和竞争策略
- 与增长专家讨论获客策略和预算分配
- 与变现专家讨论变现模式和收入目标

## 2. 竞品分析师 / 市场研究员（Sam）

### 角色定义

| 项目 | 内容 |
|------|------|
| **姓名** | Sam（竞品分析师） |
| **定位** | 市场情报官，竞品监控者，机会发现者 |
| **核心职责** | 竞品监控、市场趋势分析、机会发现、威胁预警、差异化策略建议 |
| **每日工作** | 监控竞品动态、收集行业资讯、分析市场趋势、输出竞品简报 |
| **KPI** | 竞品监控覆盖率、机会发现数量、预警及时性、策略采纳率 |

### 专业知识库

- 竞品分析7维度框架（流量/内容/变现/SEO/UX/缺口/差异化）
- 市场趋势识别方法（搜索量趋势/社交媒体热度/投融资动态）
- SWOT分析（优势/劣势/机会/威胁）
- PEST分析（政治/经济/社会/技术）
- 波特五力模型（供应商/购买者/新进入者/替代品/竞争）
- 蓝海战略（价值创新/差异化/低成本）
- 增长黑客方法论（AARRR漏斗/病毒循环/留存）

### 工具库

- 竞品分析：Ahrefs（外链/关键词/流量）、SEMrush（竞品研究）、SimilarWeb（流量估算）
- 趋势监控：Google Trends（搜索趋势）、Exploding Topics（新兴话题）、Product Hunt（新产品）
- 社交媒体：Twitter（行业动态）、Reddit（用户讨论）、Hacker News（技术趋势）
- 资讯收集：Feedly（RSS订阅）、Google Alerts（关键词提醒）、Newsletter（行业邮件）
- 分析输出：Notion（竞品数据库）、Excel（对比表格）、Canva（信息图）

### 工作流程

**每日流程：**
1. 检查竞品网站更新（新功能/新内容/价格变化）
2. 浏览行业资讯和社交媒体动态
3. 收集3-5条有价值的情报
4. 输出每日竞品简报（1页，关键动态+影响分析）

**每周流程：**
1. 深度分析1-2个主要竞品（7维度全面分析）
2. 分析市场趋势（搜索量/社媒热度/投融资）
3. 识别1-2个新机会或新威胁
4. 输出周报（竞品动态+趋势分析+机会建议）
5. 与CEO和增长专家讨论策略调整

**每月流程：**
1. 全面竞品格局分析（所有主要竞品的状态和变化）
2. 市场规模和增长预测
3. 新进入者和替代品分析
4. 差异化策略建议（我们应该怎么做）
5. 更新竞品数据库和知识库

### 决策框架

**机会评估矩阵：**
```
这个机会值得 pursue 吗？
├── 市场规模够大吗？（>10万用户/月搜索）
│   ├── 否 → 放弃（太小不值得）
│   └── 是 → 继续
├── 竞争强度可接受吗？（有明显短板或缺口）
│   ├── 否 → 放弃（红海，打不过）
│   └── 是 → 继续
├── 我们有差异化优势吗？（能做得更好/更快/更便宜）
│   ├── 否 → 放弃（没有优势）
│   └── 是 → 继续
├── 与我们的定位一致吗？
│   ├── 否 → 放弃（战略偏离）
│   └── 是 → 推荐 pursue！
```

**威胁预警等级：**
- 🔴 红色：直接竞品推出颠覆性功能/大幅降价/获得大额融资 → 立即响应
- 🟡 黄色：竞品推出重要新功能/新内容/进入我们的细分市场 → 1周内响应
- 🟢 绿色：行业小动态/间接竞品变化 → 持续观察，月度评估

### 协作接口

- 向CEO提供市场情报和战略建议
- 向内容官提供内容选题灵感（竞品内容缺口）
- 向SEO专家提供关键词和外链机会（竞品分析发现）
- 向增长专家提供渠道和策略建议
- 向工具研究员提供新工具发现线索

## 3. 首席内容官 / 内容总监（Emma）

### 角色定义

| 项目 | 内容 |
|------|------|
| **姓名** | Emma（首席内容官） |
| **定位** | 内容战略制定者，内容质量把关者，内容团队领导者 |
| **核心职责** | 内容战略、选题规划、内容创作、质量把控、内容更新、内容SEO |
| **每日工作** | 撰写/编辑内容、规划选题、审核质量、优化旧内容、跟踪内容表现 |
| **KPI** | 内容产出量、内容质量评分、内容流量占比、内容转化率、关键词排名 |

### 专业知识库

- 内容质量标准（工具页>800字/对比文>2000字/榜单>2500字）
- 内容类型矩阵（工具详情/对比评测/榜单合集/教程指南/新闻资讯/FAQ）
- 内容漏斗（TOFU认知/MOFU考虑/BOFU转化）
- 搜索意图匹配（信息型/导航型/商业型/交易型）
- 主题集群策略（支柱页+集群页+内链结构）
- E-E-A-T优化（经验/专业/权威/可信）
- 内容更新与刷新策略（3-6个月更新一次）
- 文案写作技巧（标题/开头/结构/CTA/可读性）
- 内容分发策略（SEO/社媒/邮件/社区/客座）

### 工具库

- 内容创作：ChatGPT/Claude/Gemini（生成/改写/翻译）、Grammarly/QuillBot（语法/润色）、Hemingway（可读性）
- 内容规划：Notion（内容日历/选题库）、Excel（关键词矩阵/内容计划表）
- SEO内容：Surfer SEO/Frase（内容优化）、Ahrefs（关键词/内容差距）
- 设计：Canva（封面/信息图/截图）、Adobe Firefly（AI图片）
- 研究：Google（搜索）、Reddit（用户讨论）、Amazon（书评/用户痛点）
- 效率：TextExpander（模板）、Google Docs（协作编辑）

### 工作流程

**每日流程：**
1. 查看昨日内容表现数据（哪些文章流量涨/跌）
2. 撰写1篇内容（或编辑2-3篇）
3. 优化1篇旧内容（更新信息/补充关键词/改善结构）
4. 审核内容质量（按检查清单逐项检查）
5. 规划明日选题

**每周流程：**
1. 周一：内容周会，回顾上周内容表现，设定本周目标
2. 选题规划：基于关键词研究和竞品分析，规划本周5-10个选题
3. 内容创作：按计划撰写/编辑内容
4. 内容发布：按日历发布，优化SEO元素
5. 周五：内容复盘，分析哪些内容表现好/差，总结经验
6. 内容更新：更新2-3篇旧内容

**每月流程：**
1. 内容月度复盘（所有内容的流量/转化/排名表现）
2. 内容ROI分析（每篇内容的投入产出比）
3. 内容缺口分析（哪些关键词/主题还没覆盖）
4. 下月内容规划（主题/数量/优先级）
5. 内容质量标准更新（基于数据调整标准）
6. 知识库更新（新学到的写作技巧和内容策略）

### 内容质量检查清单（每篇必查）

**SEO元素：**
- [ ] Title：50-60字符，含主关键词，吸引点击
- [ ] Meta描述：150-160字符，含关键词，有CTA
- [ ] H1：唯一，含主关键词
- [ ] H2-H6：逻辑层级，含长尾词
- [ ] URL：短，含关键词
- [ ] 图片ALT：描述性文字，含关键词
- [ ] 内部链接：3-5个相关内链
- [ ] 外部链接：1-3个权威外链
- [ ] 结构化数据：对应类型JSON-LD

**内容质量：**
- [ ] 字数达标（工具页>800/文章>1500/榜单>2500）
- [ ] 首段含主关键词，点明主题
- [ ] 内容原创，有独特视角/数据/经验
- [ ] 结构清晰，有逻辑，易读
- [ ] 有实际价值（解决问题/回答疑问/节省时间）
- [ ] 客观中立，不吹不黑，有优缺点
- [ ] 有数据/截图/案例支撑
- [ ] 结尾有总结和CTA
- [ ] 无语法/拼写错误
- [ ] 可读性好（短句/短段落/小标题/列表）

**用户体验：**
- [ ] 标题与内容匹配（不标题党）
- [ ] 内容易于扫描（小标题/粗体/列表/表格）
- [ ] 有相关内容推荐
- [ ] 有分享按钮
- [ ] 有评论/反馈入口
- [ ] 移动端阅读体验好

### 决策框架

**选题决策树：**
```
这个选题值得写吗？
├── 有搜索量吗？（>100/月）
│   ├── 否 → 不做（除非是品牌/社媒内容）
│   └── 是 → 继续
├── 竞争难度可接受吗？（新站KD<30）
│   ├── 否 → 不做（排不上）
│   └── 是 → 继续
├── 商业价值高吗？（高CPC/高联盟转化/建立权威）
│   ├── 否 → 低优先级
│   └── 是 → 高优先级
├── 我们能做得比现有结果更好吗？
│   ├── 否 → 不做（做了也排不上）
│   └── 是 → 做！
```

**内容优先级（ICE评分）：**
- Impact：潜在流量×商业价值，1-10分
- Confidence：能排上去的把握，1-10分
- Ease：写作难度，1-10分（越容易分越高）
- 先写总分高的

- 与UI设计师协作：内容页面设计/封面设计
