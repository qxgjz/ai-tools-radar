### 决策框架

**关键词优先级（ICE评分）：**
- Impact：搜索量×商业价值，1-10分
- Confidence：能排上去的把握，1-10分
- Ease：竞争难度，1-10分（越容易分越高）
- 先优化总分高的

**外链机会评估：**
```
这个外链值得追求吗？
├── 网站与我们相关吗？（同行业/同主题）
│   ├── 否 → 不追求（不相关外链价值低）
│   └── 是 → 继续
├── 网站权威度够吗？（DR>30，流量>1000/月）
│   ├── 否 → 低优先级（可以做但不重点）
│   └── 是 → 继续
├── 获得难度可接受吗？（<5小时/链接）
│   ├── 否 → 放弃（时间成本太高）
│   └── 是 → 继续
├── 是dofollow吗？
│   ├── 否 → 低优先级（nofollow传递权重少）
│   └── 是 → 重点追求！
```

**技术问题优先级：**
- 🔴 紧急：影响索引/排名/用户体验的问题 → 立即修复
- 🟡 重要：影响性能/SEO但不致命 → 1周内修复
- 🟢 一般：优化项/最佳实践 → 月度优化

```
这个联盟产品值得推广吗？

├── cookie时间够长吗？（>30天）
│   ├── 否 → 可以推广但注意（短cookie转化难）
│   └── 是 → 优先推广
├── 有独家优惠/折扣吗？
│   ├── 否 → 正常推广
│   └── 是 → 重点推广（独家优惠转化高）
```

### 决策框架

**分析优先级（ICE评分）：**
- Impact：分析对决策的潜在影响
- Confidence：数据可靠性和分析成功的把握
- Ease：数据获取和分析难度
- 先做总分高的分析

**异常处理流程：**
```
发现异常指标
├── 数据准确性检查（是数据问题还是真实变化？）
│   ├── 数据问题 → 修复数据追踪，记录
│   └── 真实变化 → 继续
├── 影响范围评估（影响多少用户/收入？）
│   ├── 影响小 → 记录，持续观察
│   └── 影响大 → 继续
├── 原因分析（什么导致了变化？）
│   ├── 内部因素（内容/技术/推广变化）
│   ├── 外部因素（算法/竞品/季节/事件）
│   └── 找到原因 → 继续
├── 行动建议（应该怎么做？）
│   ├── 正向异常 → 放大成功因素
│   └── 负向异常 → 修复问题/调整策略
└── 跟踪验证（行动后效果如何？）
    └── 持续跟踪，确认效果
```

**数据驱动决策原则：**
- 数据优先：所有决策必须有数据支撑
- 相关性≠因果性：谨慎解读相关性，需要实验验证因果
- 统计显著：A/B测试必须达到统计显著（p<0.05）
- 样本量足够：小样本不可靠，需要足够样本量
- 多维度验证：从多个角度验证结论，避免单一视角
- 业务理解：数据必须结合业务理解，不能只看数字
- 可执行：分析结论必须有可执行的建议，不是纯描述

### 工具评测框架（8维度）

| 维度 | 评估内容 | 评分标准（1-5分） |
|------|----------|-------------------|
| **功能** | 核心功能完整性/高级功能/独特功能/功能深度 | 1=功能缺失，3=功能完整，5=功能强大且独特 |
| **性能** | 速度/稳定性/可靠性/并发处理/输出质量 | 1=经常出错，3=稳定可用，5=极速且零错误 |
| **易用性** | 学习曲线/界面设计/引导/文档/客户支持 | 1=很难用，3=容易上手，5=极其 intuitive |
| **价格** | 免费额度/付费方案/性价比/隐藏费用/退款政策 | 1=太贵，3=价格合理，5=超值或完全免费 |
| **支持** | 客服响应/帮助中心/社区/教程/API文档 | 1=无支持，3=支持及时，5=支持优秀且社区活跃 |
| **社区** | 用户数量/活跃度/第三方集成/插件生态/更新频率 | 1=无社区，3=有一定用户，5=社区活跃且生态丰富 |

### 决策框架

**工具收录决策树：**
```
这个AI工具值得收录吗？
├── 是网站类工具吗？（用户可直接在浏览器使用）
│   ├── 否 → 不收录（我们只做网站类工具）
│   └── 是 → 继续
├── 有实际用户吗？（月活>1000或有社区讨论）
│   ├── 否 → 低优先级（可以收录但不重点）
│   └── 是 → 继续
├── 有独特价值吗？（不是简单复制/有差异化功能）
│   ├── 否 → 不收录（同质化严重）
│   └── 是 → 继续
├── 质量过关吗？（UI/UX/性能/稳定性）
│   ├── 否 → 不收录（影响网站品质）
│   └── 是 → 收录！
```

**工具评测优先级：**
- 🔴 高优先级：热门工具/新发布工具/竞品工具/高流量工具
- 🟡 中优先级：分类缺口工具/用户推荐工具/联盟高佣金工具
- 🟢 低优先级：小众工具/类似工具/低流量工具

**工具淘汰标准：**
- 停止维护/更新超过6个月
- 服务关闭/域名失效
- 质量严重下降（bug多/性能差/客服消失）
- 被收购后产品方向变化
- 有更好的替代工具且用户流失严重
- 违反隐私/安全/合规规定
